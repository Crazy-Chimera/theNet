# Iteration 41 — Evolution History Root Contract\n\n## Purpose\n\nCreate a deterministic, immutable root identifier for an audited evolution history.\n\nThe root is a compact integrity reference for a history snapshot. It does not replace the underlying commits or the Iteration 40 audit.\n\n## Input\n\n- commits: iterable of EvolutionCommit\n- initial_state_id: optional non-empty state identifier\n\n## Output\n\nEvolutionHistoryRoot:\n\n- root_id\n- commit_count\n- initial_state_id\n- audit\n- version = 1\n\n## Root identity\n\nThe root is SHA-256 over a canonical representation of version, initial state identifier, ordered audited commit identifiers, ordered predecessor state identifiers, and ordered branch state identifiers.\n\nOrdering is deterministic and independent of input iterable order.\n\n## Invariants\n\n1. Invalid evolution history cannot produce a root.\n2. The same valid history produces the same root.\n3. Reordering the same history does not change the root.\n4. Changing a commit changes the root.\n5. Changing the initial-state anchor changes the root.\n6. The returned object is immutable.\n7. Input iterables are not mutated.\n8. No external services are required.\n9. The root is an integrity reference, not a consensus proof.\n10. The root does not itself grant contribution, verification, convergence, meaning, or authority.\n\n## Boundary\n\nIteration 40 audits the history.\n\nIteration 41 derives a deterministic root from that audited history.\n\nLater layers may persist, reference, synchronize, or challenge the root.
